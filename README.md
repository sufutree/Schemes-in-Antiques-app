# 古董局中局（多人手機版）

6–8 人桌遊《古董局中局》的輔助網頁。每人用自己的手機打開網址、輸入房號加入，身份與鑑定結果只會出現在自己的手機上；不需要安裝 App、不需要註冊帳號。

## 功能

- **開房 / 加入**：房主開房得到 4 位數房號與 QR code，朋友掃描或輸入房號加入
- **座位**：房主可以依現場實際座位調整順序（影響發言順序）
- **發身份**：每人在自己手機上看身份，老朝奉與藥不然互相知道隊友
- **行動**：輪到誰，誰的手機會震動；鑑定、發動能力、派票都在自己手機上完成，其他人只看得到「誰派票給誰」
- **發言**：依尾家左手邊開始的順序顯示目前發言者，說完按一下換下一位
- **投票**：每人在手機上分配籌碼（每輪 +2 枚，沒用完的留到下一輪，最後一輪必須投完），全部投完同時開票並公開每個人的票
- **身份揭露與結算**：自動計分，結束後公開所有身份、真相與每個人的行動紀錄
- **紀錄**：隨時回看自己的私人紀錄，以及每一輪的派票順序、發言順序、開票結果與每個人的票
- **筆記**：每輪記下每個人說哪件寶物是真／贗／無法鑑定、你覺得他偏好人還是偏壞人，加上備註；存在伺服器、只有自己看得到
- **房主代為操作**：有人手機沒電或不回應時，房主可以代為結束他的回合（隨機派票），或在看身份、投票、指認時不再等待
- **斷線重連**：重新整理或關掉再開都會回到原本的房間；換手機可用「我的身份與紀錄」裡的重連連結

## 規則實作細節

| 狀況 | 處理方式 |
|---|---|
| 老朝奉發動 | 本輪排在他後面的好人（姬云浮除外）看到的四件寶物真假全部互換 |
| 鄭國渠覆蓋 | 之後鑑定那件寶物的人（包括老朝奉陣營）只看到「無法鑑定」 |
| 藥不然偷襲 | 對方「下一次輪到時」無法鑑定、無法發動能力，但仍要派票。若對方本輪已行動，就是下一輪生效 |
| 偷襲方震 | 許願也一併被偷襲 |
| 偷襲姬云浮 | 姬云浮整場都無法再鑑定 |
| 木戶加奈 / 黃煙煙 | 隨機一輪無法鑑定，輪到時才會知道 |
| 平票 | 依十二生肖順序，鼠最高、豬最低 |
| 好人指認老朝奉 | 依原規則「過半（含）」，也就是剛好一半也算 |
| 鄭國渠 | 不參與最後的指認 |

## 架構

```
public/        前端（純 HTML/CSS/JS，不需要編譯）
api/game.js    Vercel Serverless Function：唯一的 API
lib/game.js    遊戲規則（全部在伺服器上執行，手機只拿得到自己能看的資料，不能作弊）
lib/store.js   房間存在 Upstash Redis；沒設定時改用記憶體（只適合本機測試）
dev-server.js  本機測試用伺服器
```

手機每 1.5 秒向伺服器詢問一次有沒有更新（切到背景時放慢到 8 秒）。房間 12 小時沒動作會自動刪除。

## 部署到 Vercel

1. 到 [vercel.com](https://vercel.com) 用 GitHub 登入 → **Add New → Project** → 選這個 repo → **Deploy**（設定都不用改）
2. 進入專案 → **Storage** 分頁 → **Create Database** → 選 **Upstash for Redis**（Marketplace，有免費方案）→ 建立後 **Connect** 到這個專案
   - Vercel 會自動加入 `KV_REST_API_URL`、`KV_REST_API_TOKEN` 這兩個環境變數
3. 回到 **Deployments** → 最新一筆右邊的 ⋯ → **Redeploy**（讓環境變數生效）
4. 打開 Vercel 給你的網址（例如 `https://xxx.vercel.app`），就可以開房了

> ⚠️ 一定要做第 2 步。沒有 Redis 的話，Vercel 上每次請求可能跑在不同的機器，房間會「消失」。

### 免費額度夠嗎？

一局 8 人約 1 小時，大約會用掉 2 萬次請求。Vercel 免費方案每月有 100 萬次函式呼叫；Upstash 免費方案每月約 50 萬次指令，大約夠玩 20 局以上。

## 本機測試

需要 Node.js 20 以上：

```bash
node dev-server.js
```

打開 http://localhost:3000 。同一個 Wi-Fi 的手機可以用 `http://<電腦的區網 IP>:3000` 連進來。可以用電腦開多個無痕視窗模擬多位玩家。
